# 구글 독스 부가기능 설치 (속기 사이드바)

독스 문서 한 개가 곧 회의록입니다. 문서에 **안건지를 직접 쓰고**, 안건마다 **속기 위치**를 정해 두면 위원들 발언이 그 자리에 `이름: 발언` 으로 쓰입니다.

## 1. 한 번만 설치 (문서마다)

1. 구글 독스에서 새 문서(또는 안건지 문서)를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**
3. 왼쪽 톱니(프로젝트 설정) → **“appsscript.json” 매니페스트 파일을 편집기에 표시** 체크
4. 편집기로 돌아가 아래 세 가지를 붙여 넣고 저장(💾)
   - `Code.gs` : 기존 내용을 지우고 `docs-addon/Code.gs` 전체
   - `appsscript.json` : `docs-addon/appsscript.json` 전체
   - 파일 추가(＋) → **HTML** → 이름 `Sidebar` → `docs-addon/Sidebar.html` 전체
5. 문서 탭으로 돌아가 **새로고침(F5)** → 메뉴에 **속기** 가 생깁니다.
6. **속기 → 사이드바 열기** → 처음 한 번 권한 승인(“확인되지 않은 앱” → 고급 → 이동 → 허용)

## 2. 처음 한 번 설정 (사이드바 ‘설정’ 탭)

- 진행 탭에서 위원회 계정(`kusis.midnight@gmail.com`)으로 로그인
- **위원 접속 주소** : Cloudflare 사이트 주소 (위원은 `주소/view/?role=member` 로 들어옴)
- **위원 명단**, **위원 비밀번호**(고유 번호, 한 번 정하면 계속 사용)
- 설정은 그 문서에 저장됩니다. 문서를 복사해 쓰면 복사본에서도 이어집니다.

## 3. 안건지 쓰기 (‘안건지’ 탭)

문서에서 커서를 놓고 누르면 그 자리에 들어갑니다.

- ① 회의 개요 · 소집 공고문
- ② 안건 추가 : 유형, 이름(‘의 건’ 자동), 발의자(명단 자동완성), 요지, **관련 회칙 찾아 넣기**, 비고 → 안건 + **속기 위치**가 함께 생김
- ③ 안건 여러 개 한 번에 (`유형|제목|발의자`)
- ④ 속기 위치 : 직접 쓴 안건 아래에 커서를 놓고 “여기를 안건 위치로” / 개의·산회 위치 지정, 이동·삭제
- 문서에 보이는 회색 `▶ 속기 위치 · …` 줄이 발언이 쓰일 자리입니다. 지우지 말고, 회의가 끝나면 진행 탭의 “속기 위치 표식 지우기”로 한 번에 정리하세요.

## 4. 회의 진행 (‘진행’ 탭)

1. **회의실 열기** → 위원이 휴대폰/컴퓨터에서 이름·비밀번호로 입장
2. 입장한 위원 중 **의장**을 눌러 지정 (출석은 입장한 위원으로 자동)
3. **개의** → 개요표(의장·출석·불참·정족수)가 ‘개의 위치’에 기록
4. 안건 **상정** → 심의안건은 정해진 절차(제안 설명 → 질의 → 찬반 토론 → 토론종결동의 → 표결), 보고·토의안건은 상정 → 종료
5. 위원은 자기 기기에서 **발언하기**를 누르고 말하면, 말이 2초 멈출 때마다 해당 안건 위치에 `이름: 발언` 으로 쓰임 (한 번에 한 명만 발언)
6. 정회/속회, 추가 안건(출석 2/3 상정 표결), 산회(심의안건 결과표가 ‘산회 위치’에 기록)
7. 참관인/위원 휴대폰 화면에서는 같은 기록과 **문서 링크**가 실시간으로 보입니다.

사이드바를 닫았다 다시 열어도 회의 중이면 이어서 연결됩니다.

## 알아둘 점

- 마이크는 **위원 기기의 접속 페이지**에서 켭니다 (독스 사이드바 안에서는 마이크가 막힐 수 있어 쓰지 않습니다).
- 진행 버튼(상정·표결·산회)은 **사이드바를 연 사람**(속기자/의장 대리)이 누릅니다. 의장은 입장한 위원 중에서 지정하며 발언은 의장 본인 기기에서 하고 `이름(의장)` 으로 기록됩니다.
- 사이드바는 한 번에 하나만 열립니다. 폭은 고정(약 300px)이라 작게 구성했습니다.
- Firebase 규칙은 기존 `docs/firebase-rules.json` 그대로 쓰면 됩니다.
- 코드를 고치면 `node docs-addon/build.js` 로 `Sidebar.html` 을 다시 만들고 Apps Script에 다시 붙여 넣습니다.
